# Data Analysis Exercise

The object of this data analysis was to merge two training datasets while understanding and upholding Commission policy with regards to maintaining data standards and security. There are two main files included in this data analyst exercise, both which respectfully pertain to different parts of the exercise. 

The file status_extraction.py provides a solution for Parts 1 & 2 of this exercise. This python program updates records from two different raw data files via ETL processing and data mapping through Python and the Pandas library. It matches MPTC USER ID records and maps the data to provide a master_output.csv file that contains a joined version of both data present in their respective datasets.

There is also analysis_automation.py, offering an automated version requested in Part 3 of the analysis exercise. This file is similar to the python file mentioned earlier, while using additional python libraries to better cater towards a user-friendly approach to implementing these files to provide scalable solutions.
